# Sunset Island · 日落岛

Public interactive preview for [Vicky’s Gallery](https://lyx1265897416-lab.github.io/vicky-gallery/).

**Play:** https://lyx1265897416-lab.github.io/sunset-island-preview/player/

Seven branching episodes, dialogue choices, gesture interactions and outfit variations. Chinese captions: `player/?lang=zh`; English: `player/?lang=en`.

This repository contains only the browser player and the confirmed media it references. The production project and its original high-resolution videos remain separate. Web copies are encoded as 720×1280 H.264/AAC MP4 with fast-start metadata; no generation services or API keys are required.

To update: export the latest confirmed `player/` and the media referenced by `player/story.json`, preserve relative paths, encode browser media, then commit and push to `main`. GitHub Pages serves this branch from the root. Keep the published site below the Pages size limit.
